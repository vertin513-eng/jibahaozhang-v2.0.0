# 多账户 v2.0.0

## 数据

```json
{
  "accounts": [
    {
      "id": "wechat",
      "name": "微信",
      "icon": "chat",
      "color": "#4F9D69",
      "initialBalance": 1000,
      "startDate": "2026-10-28"
    }
  ],
  "transactions": [
    { "type": "expense", "accountId": "wechat", "amount": 100, "category": "lunch" },
    { "type": "income", "accountId": "alipay", "amount": 50, "category": "income" },
    { "type": "transfer", "fromAccountId": "wechat", "toAccountId": "bank", "amount": 200 }
  ]
}
```

- 默认账户：`wechat` 微信、`alipay` 支付宝、`bank` 银行卡。
- 新账户 `id = acc_...`，初始余额 0、基准日期为创建当天。
- 支出 / 收入必须有 `accountId`；旧数据缺失时归入银行卡（或第一个账户）。
- 转账没有 `accountId` / `category`，只有 `fromAccountId` / `toAccountId`。

## 余额

```text
账户余额 = 初始余额
         + 该账户 date >= startDate 的收入
         - 该账户 date >= startDate 的支出
         + 转入（date >= startDate）
         - 转出（date >= startDate）

总资产 = Σ 所有账户余额
```

- 转账在账户余额中一减一加，总资产不变。
- 转账不计入 `summarize()`、日历、预算、分类统计、备注统计；`statsList()` 会过滤转账。
- 账户明细列表包含转账，按转入 / 转出显示。

## Store API

- `accounts()` / `accountById(id)` / `accountSummary(id)` / `accountsSummary()`
- `accountTransactions(id)`：该账户的收支 + 转出 + 转入
- `statsList(list, accountId)`：统计用，过滤转账，可限定账户
- `addAccount({name,icon,color})` / `updateAccount(id,{name,icon,color})`
- `getAccountOpening(id)` / `setAccountOpening(id, initial, startDate)`
- `defaultAccountId()`：上次使用账户，回退到第一个账户
- `isTransfer(t)`

## 页面

- `accounts`：账户总览，顶部总资产 + 账户列表 + 转账 / 新增账户。
- `account`：账户明细，账户余额 + 本月四项汇总 + 该账户流水。
- 首页「账户总余额」点击进入 `accounts`，不再打开单账户设置面板。
- 记账面板增加账户 chips；转账面板独立，双账户 chips + 金额 + 备注 + 日期时间。
- 统计页增加账户筛选 chips；选择单账户时隐藏预算口径的累计结余卡。

## 迁移

`migrate(raw)`：

- 没有 `accounts` 时创建默认 3 个账户。
- 旧 `settings.accountInitialBalance` / `accountStartDate` 迁移到 `bank`。
- 旧账单没有 `accountId` 时全部归入 `bank`。
- 旧 `accountBalance` / `accountInitialBalance` / `accountStartDate` 从 settings 删除。
- 新数据保留 accounts，旧账单按账户补齐。

## 导出 / 备份

- CSV / Excel 新增「账户」列：`日期,时间,类型,账户,分类,金额,备注`。
- 转账导出为类型「转账」、账户「微信 → 银行卡」、分类「转账」。
- JSON 备份包含 accounts 和 transfer 记录；security 仍然不进入备份，恢复时保留本机解锁设置。

## 已知限制

- 快捷记账（悬浮球 / 通知栏 / 导入）默认使用上次使用的账户；导入预览顶部可选择本批账单账户。
- 转账按各账户自己的基准日期计入余额；若转账日期早于某个账户的基准日期，该账户不计这笔转账（与“基准日期之前流水不参与”规则一致）。
- 账户暂不支持删除，避免历史账单失去归属；可重命名 / 改图标颜色。
