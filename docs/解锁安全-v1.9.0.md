# 解锁安全 v1.9.0

## 目标

打开 App 先验证身份；支持 6 位数字密码与设备指纹；错误次数限制；切后台 / 闲置重新验证；提供修改密码与关闭入口；验证前不渲染账目。

## 数据

安全设置存在 `settings.security`：

```json
{
  "setupDone": true,
  "enabled": true,
  "pinEnabled": true,
  "biometricEnabled": true,
  "pinHash": "base64(PBKDF2-SHA256)",
  "pinSalt": "base64(random 16 bytes)",
  "failedAttempts": 0,
  "lockUntil": 0
}
```

- `setupDone`：是否完成过首次设置。未完成时强制进入设置页。
- `enabled`：是否启用解锁验证；由两种方式任一开启决定。
- `pinHash` / `pinSalt`：PBKDF2-SHA256，120000 次迭代，随机 16 字节盐。
- `failedAttempts` / `lockUntil`：跨重启保留的防暴力状态。
- 关闭解锁验证会清空 `pinHash` / `pinSalt`；重开需要重新设置密码。
- JSON 备份会删除 `settings.security`；`Store.restore()` 保留当前设备的 security，避免旧备份关闭锁定。

## 防暴力

- 第 5 次错误：等待 30 秒。
- 第 6 次：60 秒；第 7 次：2 分钟；第 8 次：5 分钟；第 9 次及以后：10 分钟。
- 等待状态写入 `lockUntil`，重启 App 仍生效。
- `verifyPin()` 每次先检查 `lockUntil`，UI 只负责展示倒计时。

## 生命周期

- `Security.init()` 在 `Store.init()` 之后调用；已启用则 `locked=true`。
- `render()` 最先检查 `state.auth` 与 `Security.isLocked()`，命中时只渲染解锁页。
- `visibilitychange` 返回前台：若已启用且没有进行中的密码流程，立即 `lockApp('background')`。
- 2 分钟无 `pointerdown` / `keydown`：`lockApp('idle')`。
- 文件选择器返回时豁免一次后台锁（`state.suppressLockOnce`），避免打断备份/导入流程。
- `lockApp()` 清空 sheet、modal、toast、导入预览等所有可能泄露数据的浮层，并重置到首页路由。

## 流程状态机

`state.auth`：

- `setup`：首次设置或重新开启；`new` → `confirm`。
- `set-pin`：仅开启密码解锁。
- `unlock`：解锁；6 位自动提交。
- `change`：`current` → `new` → `confirm`。
- `disable`：验证当前密码/指纹后关闭。
- `allowCancel`：首次设置 false，其余 true。
- 指纹结果通过 `window.QHSecurity.onBiometricResult(ok, message)` 从原生回传。

## Android 指纹

`MainActivity` 的 `QHAndroid` 桥新增：

- `biometricStatus()`：`ok` / `no_hardware` / `not_enrolled` / `unsupported` / `unavailable`。
- `authenticateBiometric()`：Android 9+ 使用 `BiometricPrompt`，`setDeviceCredentialAllowed(false)`，只允许指纹。

细节：

- 状态检查用 `FingerprintManager`（API 28+）。
- 原生结果通过 `evaluateJavascript` 调 `QHSecurity.onBiometricResult`；手指不匹配调 `onBiometricFailed`，不关闭系统弹窗。
- 使用 `AtomicBoolean` 防止取消按钮和错误回调重复上报。
- 所有回调都 `runOnUiThread` 后执行。

## 已知限制

- 指纹解锁依赖 Android 9+ 且系统已录入指纹；更老系统或未录入时只能使用密码。
- 6 位数字密码本身强度有限，安全主要依赖 PBKDF2 与本地递增锁定；忘记密码无法找回，只能清除应用数据（账单会丢失）。
- 未做真机指纹传感器测试，需在 Android 设备上实测一次 BiometricPrompt。
